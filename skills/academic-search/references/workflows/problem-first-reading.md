# 项目起步与阅读迭代

适用于用户只有项目主题、研究问题尚未明确，或希望先读懂少量材料再决定探索方向的情形。此流程优先于主文件中默认的 20–30 条初筛、5–10 篇深挖及前沿论文排序。用户明确要求全量检索、系统综述或固定范围批量处理时，按其当前任务执行，不将此偏好变成额外审批流程。

## 入门时先看一个做法

从用户手头的一张图、一段方法或一个待解决的小问题开始。先用几句话介绍熟悉这个领域的人通常会先看什么、据此作什么判断、怎样检验判断。挑一个关键决定讲透，最好让用户看到哪条线索会改变下一步。引用具体专家或团队的做法时给出可核对的出处；自行构造的示例直接标为演示。

例如，初学者拿到一张模型消融表，可以演示研究者怎样找出只有一个模块不同的两行，再读指标差值。如果两行连训练数据也换了，就需要另找对照，才能判断这个模块的贡献。接着可以请用户在同一张表中找另一组，或把这个办法用到自己的实验上。用户只想听介绍时，示范讲到判断依据即可；已经提出具体任务时，直接处理那个任务。

## 先看手头材料，再形成问题

- 可以从一个项目主题开始。研究问题在阅读和讨论后逐步具体化。
- 先查看用户指定或当前项目中的已有材料，包括项目说明、需求、论文、专利、方案和读书笔记。材料少时先全部阅读，再归纳已有认识与疑问，不因最初尚无明确问题就立即外部大规模检索。
- 如果现有资料库很大，不把整库都视为起步材料；先说明范围并确定与当前主题相关的一小组，不擅自扩展为全库阅读。
- 没有材料时，先围绕任务、使用场景、已有能力和困难讨论；可以借鉴用户已有的其他项目或相关论文经验。迁移时说明原条件、目标条件及待验证之处，不把类比当成目标场景的证据。
- 读完后用简短说明与用户共同形成可调整的工作问题：当前想弄清什么、材料已解释什么、仍缺什么。不要只列一长串泛化的“研究空白”供用户挑选。

## 检索分工与候选判断

- 非计算机领域，默认及时提醒用户自行在其可用数据库或图书馆检索并获取论文；助手可以协助形成检索词、识别术语、核对元数据、阅读和比较用户提供的候选材料，不自行包办“代表性论文”的来源选择与最终精选。
- 计算机领域可以更多由助手协助检索，但只改变分工，不改变研究阶段的顺序。无论学科，前期先理解已有材料、形成问题，不默认一股脑搜集多篇论文；多篇检索默认放在后期补充阶段，围绕已经形成的具体方向对照别人做过什么、哪些问题可能尚未覆盖，以及本项目还缺什么证据。用户明确要求助手在其他领域检索时，也按授权执行，并说明实际覆盖范围与访问限制。
- 不将容易获取全文等同于值得优先阅读。相关但暂时拿不到全文的文献保留为候选，提醒用户获取，不以易访问的论文默默替代。
- 检查候选文献是否因下载方便而集中于 MDPI 等某一家出版商。若结果过于集中，说明来源分布，并提醒用户从其他数据库补充检索。
- 标题、摘要和全文的判断分开。仅见摘要时说明判断范围，不声称已读全文或足以确认方法适配。
- 在读完已有少量材料并形成初步问题后，与用户一起从候选中确定一两篇精读材料。这是每轮深入理解的焦点，不是限制起步阶段只能读一两篇，也不是由助手独自敲定阅读清单。
- 选择理由围绕它能回答的具体疑问、方法与验证的清晰度、与目标场景的关系；不机械优先最新、引用最多、名气最大或开放获取的论文。

## 精读、Zotero 记录与下一轮

- 每篇重点解释：研究对象和条件、实际解决的问题、方法为何这样设计、实验支持什么、哪些条件下可迁移，以及仍未解答的问题。
- 保留用户形成自己理解与判断的环节。用户在 Zotero 中高亮和写注释；助手协助解释具体段落、核对理解、比较证据，并将未解问题整理为下一轮方向，不把助手的长篇总结当成用户已经理解的证明。
- 可以建议高亮支撑关键结论的原文，并在注释中记录“我的理解／对项目的启发／尚待核实的问题”；不强制颜色体系或额外表单。能定位时保留页码、章节、图表号或 DOI，区分作者结论、用户理解与助手推断。
- Zotero 操作仅在有实际连接和工具、且操作属于授权范围时执行；否则基于用户提供的 PDF、导出注释或文字协作，说明没有直接修改 Zotero。
- 下一轮只围绕本轮剩下的具体疑问补充检索或阅读，说明补什么及其用途。后期可以按需检索多篇来比较已有方法与覆盖范围，但“检索未发现”不能直接写成“从未有人做过”。方向已清楚时可以继续用户已授权的工作，不每步都停下来索取确认。
- 当当前问题已有足够解释，先讨论理解和下一步判断，不为了数量、覆盖率或“更全面”继续堆积材料。

## 何时主动提醒

在只有项目名就开始扩大检索、未读完手头少量资料又继续收集、候选明显受全文可得性影响、非计算机领域由助手独自精选，或用户尚未消化精读内容就要求下一批时，简短提醒一次，并给出可执行的下一步。不要反复说教或把提醒变成拒绝工作的理由。

示例：“我们先把手头这几份读完，看看具体卡在哪。需要补文献时，你在熟悉的数据库检索下载，我来比较内容，再一起确定精读哪一两篇。”
